# Atomic-VAEP with Tracking Data

An extension of the Atomic-VAEP model for valuing football actions: it adds an estimate of each action's chance of success, computed from tracking-data context features.

Data Science Applied to Football course (UFMG, 2025/1). Group project.

## Approach

1. Convert event data to SPADL / atomic SPADL with `kloppy` (`kloppy_to_spadl.ipynb`).
2. Clean the tracking data: filter frames, fix play direction, handle the goalkeeper (`tracking/`).
3. Build context features from tracking around each action: team compactness, pressure, passing triangle, player speed and goalkeeper angle.
4. Train an XGBoost classifier that estimates the probability that an action succeeds.
5. Add that probability as a feature of the Atomic-VAEP scoring and conceding models.

Notebooks `1.1` to `1.4` compare the baseline with variants using different feature sets; `vaep_completo.ipynb` is the full pipeline.

## Results

- Success classifier: ROC AUC about 0.95 on the test set.
- Atomic-VAEP "scores" model (baseline and final notebooks): test ROC AUC 0.786 for the baseline and 0.793 with the success feature. Brier score and log loss are practically unchanged, so the gain is small.

## Data

Event and tracking data (Premier League matches) are not included because of size and licensing. The notebooks expect the intermediate files (`raw_events/`, `spadl_events/`, `tracking/`, `tracking_features/`) to be generated by the steps above.
